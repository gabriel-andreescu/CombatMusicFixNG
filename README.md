# CombatMusicFixNG

Stops lingering combat music.

This project uses
[BethesdaModKit (BMK)](https://github.com/gabriel-andreescu/BethesdaModKit) for
project generation and development tooling.

## Development

```powershell
xmake
xmake package
```
